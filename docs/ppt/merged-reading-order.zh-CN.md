## 生成与检查

```bash
python3 docs/ppt/build-merged.py --output /tmp/darwin-merged.pptx
```

脚本固定两份源文件的 SHA-256。源文件变化时停止生成，需要先复核内容再更新校验值。已有输出必须提供准确的 `--replace-sha256` 才能覆盖。

实验稿保留在原有 PPTX 包中，以保留图表、工作簿和图片关系。架构稿只含原生图形；脚本检查并拒绝带有额外资源关系的页面，再复制图形并建立独立的备注页。所有页面都在备注中注明原稿页码。

交付前检查页序、隐藏状态、备注与对应页的关系、图片和图表内容、数据表、资源引用，以及渲染后的文字。两份原稿不作为生成目标。

XML 校验以实验原稿为对照，没有新增错误。原稿 `ppt/charts/chart1.xml` 中已有空 `c:ext` 扩展节点，单独做严格 XSD 校验会提示缺少子元素；合并时未改动这些图表节点或数据。

PDF 预览包含全部 41 页，便于查阅。PPT 中最后两页继续隐藏，不会在默认放映中出现。
