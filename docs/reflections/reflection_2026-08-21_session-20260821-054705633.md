Turn 15 / seq 309 read 1,232,275 cache tokens, turn 19 / seq 406 read 1,742,620 and emitted 10,487 output tokens, turn 20 / seq 479 read 2,446,242, and turn 21 / seq 507 read another 1,573,324. - **Suggestion:** Reuse Darwin’s existing context estimate to emit one bounded transcript notice when a session crosses a configurable high-pressure threshold, recommending `/compact` before the next broad implementation or verification turn. Keep compaction user-controlled and do not add a live-frame row or silently alter conversation state.

- **Evidence:** At turn 15 / seq 236–237, `fileEditor str_replace` rejected an `old_str` that no longer appeared verbatim after earlier PRD edits. The model had to construct and issue a corrected replacement at seq 239–240. The error named the missing text and file but supplied no bounded current surrounding text.
- **Root-cause area:** tool description
- **Suggestion:** On a failed `fileEditor str_replace`, return a bounded, line-numbered excerpt around the closest current textual match (or explicitly state that no safe close match exists), without applying a fuzzy edit. This keeps writes exact while reducing rereads and retry latency.
