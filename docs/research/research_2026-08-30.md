### Comparison and gaps

| Peer evidence | Darwin evidence | Parity / gap / deliberate difference | Implication |
|---|---|---|---|
| Claude Code dynamic workflows: the script holds the plan; results flow worker-to-worker (S3) | `SubagentTool` single-task delegation only; inter-step data flows through the parent context | **Gap.** Darwin's parent must replay every intermediate report and re-decide each step; multi-step pipelines (research → implement → check) cost parent context and are not declaratively expressible | A bounded declarative DAG tool closes the gap without a new engine |
| SDK `Graph`: dependency-merged inputs, bounded concurrency, cancellation, timeouts (S2) | No SDK `multiagent/` usage in `src/` | **Unadopted SDK capability** — the classic `sdk`-path finding | Adopt `Graph` as the executor; darwin supplies only node construction (its existing child recipe) and validation |
