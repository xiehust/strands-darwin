### Recommendation

- Batch: **SER-115 only**, Priority 154, appended to `backlog/directions-141-160.md`; no index route change. Gate rechecked at selection without rating changes.
- Command contract: `darwin completion bash` (including the existing one leading `--`) prints deterministic Bash source and exits 0 with empty stderr. Missing/unknown shell or extra operands are exit-2 usage errors. Help/version retain their existing precedence. Keep SDK marker preflight first; dispatch must not load runtime, config, sessions, hooks or MCP.
- Completion contract: static top-level commands and flags from the actual CLI grammar, valid immediate subcommand verbs, fixed `--permission-mode` / `--output-format` / completion-shell values, and known option spellings in their applicable contexts. Values that are free-form (prompt, IDs, rules, URLs, credentials, server names, paths, numbers) get no fabricated suggestions. Consume option operands as operands: a prompt containing a command name must not switch completion context. No filesystem/session/MCP scan, subprocess, network, automatic file install, or eval of user input; no dynamic path fallback. Bash built-ins only when completing.
- Keep scope small: an explicit supported grammar table with drift tests is sufficient; do not replace CLI parsers, change existing argument semantics, add dependencies, or add other shells in this direction.
- Independent checks: run the production source CLI in owned temporary HOME/cwd with invalid config and sentinel hook/MCP config; generation and malformed invocations must leave state byte-identical and produce no sentinel work. Source output in real `bash --noprofile --norc`, drive `COMP_WORDS`/`COMP_CWORD`, and assert actual `COMPREPLY` for root flags/commands, nested verbs, enum prefixes, consumed free operands, unsupported contexts and metacharacter input. Compare candidate grammar with authoritative parser/usage vocabulary; shell text cannot execute supplied strings. Existing `verify-cli-args.ts` and `verify-npm-patch-format.ts`, new registered fast suite, `pnpm typecheck`, `pnpm test`, and `pnpm build` must pass. README, getting-started narrative and reference in English/Chinese plus architecture rationale must explain manual installation and Bash-only/static limitations.
- Implementation stays inside a fresh source-launched `developer` child with repository-authorized code/tests/docs/commit scope. Host owns backlog/report/iteration-log closure and final ordinary push. No config, policy, credentials, dependencies or user shell startup-file mutation is authorized.
