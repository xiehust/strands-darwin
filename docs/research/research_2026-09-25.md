Result: stateless replay needs no `id`. The minimal shapes are C for Kimi (plain text) and D for GPT (opaque).

**Prototype: three changes to `responses-adapter.js` in the SDK copy (measured)**

1. `mapResponsesEventToSDK`: treat `response.reasoning.delta` like `response.reasoning_text.delta`.
2. `mapResponsesEventToSDK`: on `response.output_item.done` with `item.type === 'reasoning'`, close the open reasoning block. If the item has `encrypted_content`, emit it as `reasoningContentDelta.signature` in its **own** block. The first draft shared one block, which would keep only the last of GPT's multiple encrypted items; this was found by reading the GPT output and fixed before the run.
3. `formatResponsesMessages`: for assistant `reasoningBlock`s, emit shape D when a `signature` is present, otherwise shape C, and put every reasoning item before that message's assistant text and `function_call` items.
